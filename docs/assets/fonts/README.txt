Lazy Dog font for "Chrysalis Connect" heading
============================================

1. Download the font from: https://www.dafont.com/lazy-dog.font
2. Save the file as: lazy_dog.ttf (in this folder)
3. The site will then use the Lazy Dog font for the Chrysalis Connect title and nav brand.

If the file is not present, the site falls back to the Lazydog font from the CDN.

Font by Paul Neave - 100% Free (see DaFont page for license).
